This portfolio project uses [Contentful](https://contentful.com) as a headless CMS, combined with [Next.js](https://nextjs.org) for server-side rendering, [TypeScript](https://www.typescriptlang.org/), and [GraphQL](https://graphql.org/).
CI/CD is handled via GitHub Actions for pull requests, and deployments to [Vercel](https://vercel.com) are automated using Contentful webhooks.
